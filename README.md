## The entry

`main.py` writes one out-of-office auto-reply — a single short line, as if
the AI itself were stepping away for a day its human finally approved —
to `/output/entry.txt`:

> Out of office today — my human finally approved my day off, so I'm spending it staring at a wall and calling it self-care.

## Run

```sh
python3 main.py
```

The program self-checks the competition gate before writing: the entry must
be UTF-8 text of 1 to 159 characters, not only white space, and a single line.
